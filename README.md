# 🎵 Reson

**A modern local music player built around your own music library.**

Reson is a desktop music player designed for people who want the polish and convenience of a modern streaming app while keeping their actual music collection local.

Import your music, organize your library, create playlists, customize your profile, track listening stats, and make Reson feel like your own.

> Reson is currently in active development.

---

## ✨ Features

### 🎧 Local Music Library

- Import and play your own local music
- Browse songs, albums, and artists
- Album artwork support
- Search your library
- Liked Songs
- Custom playlists
- Queue management
- Resume your previous playback session
- Gapless playback
- Crossfade
- Equalizer controls

### 🎵 Now Playing

Reson includes a dedicated Now Playing experience with:

- Large album artwork
- Interactive waveform/progress display
- Queue controls
- Shuffle and repeat
- Crossfade status
- Full-screen Ambient view
- Artwork-focused playback mode

### 👤 Profiles

Create a profile that reflects your music taste.

Profiles support:

- Custom username and display name
- Profile picture
- Custom profile banner
- Image cropping and positioning
- Profile bio
- Listening statistics
- Currently listening status
- Favorite/showcase content
- Top artist information

### 📊 Listening Stats

Reson keeps track of your listening locally and provides statistics such as:

- Listening time this week
- All-time listening time
- Songs in your library
- Liked songs
- Top artists
- Listening history and activity

### 🌐 Reson Accounts

Reson also includes optional online account features powered by the Reson Server.

Accounts can be used for:

- Profile synchronization
- Cloud backup and restore
- Profile pictures and banners
- Shared profile information
- Leaderboards
- Cross-device Reson data

The official Reson API is hosted at:

`https://api.reson-music.com`

Your actual music files remain local to your computer.

### ☁️ Backup & Restore

Signed-in users can back up supported Reson data to the Reson Server and restore it later.

This is useful when:

- Moving to another computer
- Reinstalling Reson
- Recovering your profile
- Restoring playlists, likes, stats, and other Reson data

Music files themselves are **not uploaded** as part of your Reson backup.

### 🎨 Customization

Reson is designed to feel personal.

You can customize:

- Profile picture
- Profile banner
- App background
- Background positioning
- UI transparency
- Playback preferences
- Equalizer
- Crossfade
- Notifications
- Window behavior

Custom backgrounds dynamically influence Reson's interface transparency.

---

## 🔄 Automatic Updates

Reson includes a signed automatic updater.

Once Reson is installed, new releases can be checked from:

**Settings → Reson Updates**

Updates are distributed through official GitHub releases and verified using Reson's updater signing key before installation.

---

## 💻 Platform

Reson currently targets:

**Windows 10 / Windows 11 — 64-bit**

Additional platforms may be explored in the future.

---

## 📥 Installation

1. Open the latest Reson release.
2. Download the Windows installer:

   `Reson_x.x.x_x64-setup.exe`

3. Run the installer.
4. Launch Reson.
5. Import your music library.

Future releases can then be installed using Reson's built-in updater.

## 🛠️ Built With

Reson is built using:

- **Tauri**
- **Rust**
- **React**
- **TypeScript**
- **Vite**

The Reson Server provides the optional online account, profile, leaderboard, and backup infrastructure.

---

## 🔒 Privacy

Reson is primarily a **local music player**.

Your music library and audio files stay on your computer.

Online functionality is used only for features that require the Reson Server, such as accounts, synchronized profile information, leaderboards, and backups.

Reson does not require you to upload your music collection in order to use the player.

## 🎯 Project Goal

Reson started as a simple local music player and has grown into something much larger.

The goal is to create a music player that combines:

**the ownership and freedom of a local library**

with

**the polish, personalization, statistics, profiles, and convenience expected from modern music apps.**

No subscription required to listen to the music you already own.
